# Spinner

An indeterminate loading indicator in three sizes.

**Beta** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/spinner)

> Usable and covered by tests, but it has not yet had a release of real-world use.

## When to use

- Short waits where progress is unknown, such as a button in a pending state.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSpinner } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add spinner`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/spinner), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltSpinner, VoltNativeButton } from '@voltui/components';

@Component({
  imports: [VoltSpinner, VoltNativeButton],
  template: `
    <!-- Decorative: the surrounding text already says what is happening -->
    <button voltButton disabled>
      <volt-spinner size="sm" />
      Saving…
    </button>

    <!-- Standalone status: announced politely as "Loading projects". Set aria-busy on the region
         that is being replaced, not on the spinner. -->
    <section aria-busy="true" aria-label="Projects">
      <div class="grid place-items-center py-12">
        <volt-spinner size="lg" label="Loading projects" />
      </div>
    </section>

    <!-- A spinner next to visible text is decorative: giving it a label as well would announce
         "Saving… Saving" twice. One status message per change. -->

    <!-- Inline, in the current text colour -->
    <p class="text-muted-foreground"><volt-spinner size="sm" /> Syncing</p>
  `,
})
export class MyComponent {}
````
