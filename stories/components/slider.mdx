# Slider

Selects a single number in a range.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/slider)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Approximate values where the exact number matters less than the position: volume, price range.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSlider } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add slider`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/slider), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltSlider } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltSlider],
  template: `
    <volt-slider [formControl]="volume" [min]="0" [max]="100" [step]="1" />
    <p>Volume: {{ volume.value }}</p>
  `,
})
export class MyComponent {
  volume = new FormControl(50, { nonNullable: true });
}
````
