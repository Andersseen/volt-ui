# Avatar

A user image with a fallback (usually initials).

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/avatar)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Identifying people in lists, comments and menus.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltAvatarFallback, VoltAvatarImage, VoltAvatar } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add avatar`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/avatar), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltAvatar, VoltAvatarImage, VoltAvatarFallback } from '@voltui/components';

@Component({
  imports: [VoltAvatar, VoltAvatarImage, VoltAvatarFallback],
  template: `
    <volt-avatar>
      <img voltAvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
      <volt-avatar-fallback>CN</volt-avatar-fallback>
    </volt-avatar>
  `,
})
export class MyComponent {}
````

## Accessibility

- Give the image meaningful `alt` text, or empty `alt` when the name is already adjacent. The fallback appears after an optional `delay`.
