# Card

A surface that groups related content with optional header, content and footer parts.

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/card)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Grouping a unit of content: a project, a plan, a settings section.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltCard,
  VoltCardHeader,
  VoltCardTitle,
  VoltCardDescription,
  VoltCardContent,
  VoltCardFooter,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add card`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/card), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import {
  VoltCard,
  VoltCardHeader,
  VoltCardTitle,
  VoltCardDescription,
  VoltCardContent,
  VoltCardFooter,
  VoltNativeButton,
} from '@voltui/components';

@Component({
  imports: [
    VoltCard,
    VoltCardHeader,
    VoltCardTitle,
    VoltCardDescription,
    VoltCardContent,
    VoltCardFooter,
    VoltNativeButton,
  ],
  template: `
    <volt-card>
      <volt-card-header>
        <volt-card-title>Card Title</volt-card-title>
        <volt-card-description>Card description goes here.</volt-card-description>
      </volt-card-header>
      <volt-card-content>
        <p>Card content</p>
      </volt-card-content>
      <volt-card-footer>
        <button voltButton type="button">Save</button>
      </volt-card-footer>
    </volt-card>

    <!-- Every part merges class with cn(): p-3 replaces the default p-6 / pt-0 -->
    <volt-card class="max-w-sm">
      <volt-card-content class="p-3 md:p-4 text-center">Compact content</volt-card-content>
      <volt-card-footer class="justify-end gap-2 border-t border-border p-3">
        <button voltButton variant="ghost" size="sm" type="button">Cancel</button>
        <button voltButton size="sm" type="button">Confirm</button>
      </volt-card-footer>
    </volt-card>
  `,
})
export class MyComponent {}
````
