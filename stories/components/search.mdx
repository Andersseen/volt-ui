# Search

A search field wrapper with an icon slot and a clear button around a native input.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/search)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Filtering a list or table, or a site search box.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSearchClear, VoltSearch } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add search`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/search), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltInput, VoltSearch, VoltSearchClear } from '@voltui/components';

@Component({
  imports: [VoltInput, VoltSearch, VoltSearchClear],
  template: `
    <volt-search class="flex items-center gap-2">
      <volt-input type="search" placeholder="Search..." />
      <volt-search-clear>Clear</volt-search-clear>
    </volt-search>
  `,
})
export class MyComponent {}
````
