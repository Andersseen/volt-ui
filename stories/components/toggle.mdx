# Toggle

A two-state button that stays pressed, such as bold in a text editor.

**Stable** · Controls · [Guide on voltui.dev](https://voltui.dev/docs/components/toggle)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- A formatting or view option that is on or off and looks like a button.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltToggle } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add toggle`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/toggle), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltToggle } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltToggle],
  template: `
    <volt-toggle [formControl]="bold" aria-label="Toggle bold">
      <lmn-bold [size]="16" />
    </volt-toggle>
  `,
})
export class MyComponent {
  bold = new FormControl(false, { nonNullable: true });
}
````
