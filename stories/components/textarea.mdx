# Textarea

A multi-line text field with variant, size, state and resize options.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/textarea)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Comments, descriptions, messages: anything longer than one line.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltTextarea } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add textarea`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/textarea), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltTextarea } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltTextarea],
  template: `
    <volt-textarea [formControl]="message" rows="4" aria-label="Message" />

    <!-- variant, size, state and class all style the native <textarea> -->
    <volt-textarea variant="filled" size="sm" state="success" class="font-mono" aria-label="Notes" />
  `,
})
export class MyComponent {
  message = new FormControl('', { nonNullable: true });
}
````
