# Switch

An on/off control for a setting that takes effect immediately.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/switch)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Enabling or disabling a feature, such as notifications or dark mode.
- Use a Checkbox when the choice is submitted later with a form.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSwitch } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add switch`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/switch), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltSwitch, VoltLabel } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltSwitch, VoltLabel],
  template: `
    <div class="flex items-center gap-2">
      <volt-switch id="airplane-mode" [formControl]="enabled" />
      <volt-label htmlFor="airplane-mode">Airplane Mode</volt-label>
    </div>
  `,
})
export class MyComponent {
  enabled = new FormControl(false, { nonNullable: true });
}
````
