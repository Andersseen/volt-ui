# Toast

Short, transient notifications raised from code with `VoltToastService`.

**Stable** · Overlays · [Guide on voltui.dev](https://voltui.dev/docs/components/toast)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Confirming a background result: saved, copied, failed.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltToastClose,
  VoltToastDescription,
  VoltToastTitle,
  VoltToast,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add toast`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/toast), as you would write it in an application:

````ts
import { Component, inject } from '@angular/core';
import { VoltNativeButton, VoltToastService } from '@voltui/components';

@Component({
  imports: [VoltNativeButton],
  template: `
    <button voltButton (click)="save()">Save</button>
    <button voltButton variant="outline" (click)="copy()">Copy link</button>
    <button voltButton variant="destructive" (click)="fail()">Fail</button>
  `,
})
export class MyComponent {
  private readonly toast = inject(VoltToastService);

  save() {
    this.toast.show({ title: 'Changes saved', description: 'Your workspace has been updated.' });
  }

  copy() {
    this.toast.success('Copied to clipboard');
  }

  fail() {
    // error toasts are announced with role="alert"
    this.toast.error('Could not save', { description: 'Check your connection and try again.' });
  }
}

// Optional, app-wide defaults:
// bootstrapApplication(App, { providers: [provideVoltToast({ placement: 'top-end', duration: 5000 })] });
````
