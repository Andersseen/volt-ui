# Tooltip

A short hint shown on hover or keyboard focus.

**Stable** · Overlays · [Guide on voltui.dev](https://voltui.dev/docs/components/tooltip)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Naming an icon button or adding brief, non-essential information.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltTooltipArrow, VoltTooltipContent, VoltTooltip } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add tooltip`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/tooltip), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltTooltip, VoltTooltipContent } from '@voltui/components';
import { VoltButton } from '@voltui/components';

@Component({
  imports: [VoltButton, VoltTooltip, VoltTooltipContent],
  template: `
    <button voltTooltip [voltTooltip]="tooltipTpl">
      <volt-button variant="outline">Hover me</volt-button>
    </button>

    <ng-template #tooltipTpl>
      <volt-tooltip-content>
        <p>This is a tooltip</p>
      </volt-tooltip-content>
    </ng-template>
  `,
})
export class MyComponent {}
````

## Accessibility

- Shows on hover and focus, hides on blur or Escape, and is linked with `aria-describedby`. Never put essential or interactive content in a tooltip.
