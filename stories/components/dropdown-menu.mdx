# Dropdown Menu

A menu of actions opened from a trigger, with labels, separators and submenus.

**Stable** · Overlays · [Guide on voltui.dev](https://voltui.dev/docs/components/dropdown-menu)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- A list of commands attached to a button, such as an account or row-actions menu.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltDropdownMenuItem,
  VoltDropdownMenuLabel,
  VoltDropdownMenuSeparator,
  VoltDropdownMenuSubmenuTrigger,
  VoltDropdownMenuTrigger,
  VoltDropdownMenu,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add dropdown-menu`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/dropdown-menu), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import {
  VoltDropdownMenu,
  VoltDropdownMenuTrigger,
  VoltDropdownMenuItem,
  VoltDropdownMenuLabel,
  VoltDropdownMenuSeparator,
} from '@voltui/components';
import { VoltNativeButton } from '@voltui/components';

@Component({
  imports: [
    VoltNativeButton,
    VoltDropdownMenu,
    VoltDropdownMenuTrigger,
    VoltDropdownMenuItem,
    VoltDropdownMenuLabel,
    VoltDropdownMenuSeparator,
  ],
  template: `
    <button voltButton variant="outline" [voltDropdownMenu]="menuTpl">Open Menu</button>

    <ng-template #menuTpl>
      <volt-dropdown-menu>
        <volt-dropdown-menu-label>My Account</volt-dropdown-menu-label>
        <volt-dropdown-menu-separator />
        <volt-dropdown-menu-item>Profile</volt-dropdown-menu-item>
        <volt-dropdown-menu-item>Settings</volt-dropdown-menu-item>
        <volt-dropdown-menu-separator />
        <volt-dropdown-menu-item>Logout</volt-dropdown-menu-item>
      </volt-dropdown-menu>
    </ng-template>
  `,
})
export class MyComponent {}
````
