# Drawer

A modal panel that slides in from an edge of the screen.

**Stable** · Overlays · [Guide on voltui.dev](https://voltui.dev/docs/components/drawer)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Mobile navigation, filters and detail panels that should not leave the page.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltDrawerClose,
  VoltDrawerContent,
  VoltDrawerDescription,
  VoltDrawerOverlay,
  VoltDrawerTitle,
  VoltDrawer,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add drawer`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/drawer), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import {
  VoltDrawer,
  VoltDrawerContent,
  VoltDrawerTitle,
  VoltDrawerDescription,
  VoltDrawerOverlay,
  VoltDrawerClose,
  VoltNativeButton,
} from '@voltui/components';

@Component({
  imports: [VoltDrawer, VoltDrawerContent, VoltDrawerTitle, VoltDrawerDescription, VoltDrawerOverlay, VoltDrawerClose, VoltNativeButton],
  template: `
    <button voltButton [voltDrawer]="drawerTpl">Open Drawer</button>

    <ng-template #drawerTpl let-close="close">
      <div voltDrawerOverlay></div>
      <div voltDrawerContent side="right">
        <div class="flex items-center justify-between p-4 border-b border-border">
          <h2 voltDrawerTitle>Menu</h2>
          <volt-drawer-close>
            <lmn-x [size]="16" />
          </volt-drawer-close>
        </div>
        <nav class="p-4" voltDrawerDescription>
          <ul class="space-y-2">
            <li><a href="#" class="block px-3 py-2 rounded-md text-sm hover:bg-muted">Home</a></li>
            <li><a href="#" class="block px-3 py-2 rounded-md text-sm hover:bg-muted">Settings</a></li>
          </ul>
        </nav>
      </div>
    </ng-template>
  `,
})
export class MyComponent {}
````
