# File Upload

A file picker directive and a drag-and-drop dropzone that report selected and rejected files.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/file-upload)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Letting people attach files, with optional type restrictions, multiple files or directories.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltFileDropzone, VoltFileUpload } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add file-upload`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/file-upload), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltFileDropzone } from '@voltui/components';

@Component({
  imports: [VoltFileDropzone],
  template: `
    <volt-file-dropzone multiple>
      Drop files here or click to upload
    </volt-file-dropzone>
  `,
})
export class MyComponent {}
````

## Accessibility

- Built around the native file input, so keyboard activation and screen-reader behaviour are the platform’s.
- Drag and drop is an enhancement only: make sure the picker button is always available.
