# Toolbar

A container that groups related controls into one tab stop with arrow-key navigation.

**Stable** · Controls · [Guide on voltui.dev](https://voltui.dev/docs/components/toolbar)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Editor or table actions with many small controls.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltToolbarButton, VoltToolbar } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add toolbar`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/toolbar), as you would write it in an application:

````ts
import { Component, signal } from '@angular/core';
import { VoltToolbar, VoltToolbarButton } from '@voltui/components';

@Component({
  imports: [VoltToolbar, VoltToolbarButton],
  template: `
    <volt-toolbar aria-label="Formatting">
      <!-- Formatting buttons are toggles: aria-pressed carries their state. -->
      <button voltToolbarButton type="button" [attr.aria-pressed]="bold()" (click)="bold.set(!bold())">
        Bold
      </button>
      <button voltToolbarButton type="button" [attr.aria-pressed]="italic()" (click)="italic.set(!italic())">
        Italic
      </button>
      <button voltToolbarButton type="button">Save</button>
    </volt-toolbar>
  `,
})
export class MyComponent {
  readonly bold = signal(false);
  readonly italic = signal(false);
}
````
