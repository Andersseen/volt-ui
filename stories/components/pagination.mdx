# Pagination

Page navigation with first/previous/next/last controls and numbered pages.

**Stable** · Controls · [Guide on voltui.dev](https://voltui.dev/docs/components/pagination)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Browsing a long list split into pages.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltPaginationButton,
  VoltPaginationFirst,
  VoltPaginationLast,
  VoltPaginationNext,
  VoltPaginationPrevious,
  VoltPagination,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add pagination`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/pagination), as you would write it in an application:

````ts
import { Component, signal } from '@angular/core';
import {
  VoltPagination,
  VoltPaginationPrevious,
  VoltPaginationButton,
  VoltPaginationNext,
} from '@voltui/components';

@Component({
  imports: [VoltPagination, VoltPaginationPrevious, VoltPaginationButton, VoltPaginationNext],
  template: `
    <volt-pagination [(page)]="page" [pageCount]="5">
      <volt-pagination-previous />
      <volt-pagination-button [page]="1" />
      <volt-pagination-button [page]="2" />
      <volt-pagination-button [page]="3" />
      <volt-pagination-next />
    </volt-pagination>
  `,
})
export class MyComponent {
  page = signal(1);
}
````
