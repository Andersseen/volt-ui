# Empty State

A placeholder for an empty collection or a search with no results, with room for an action.

**Beta** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/empty-state)

> Usable and covered by tests, but it has not yet had a release of real-world use.

## When to use

- First-use screens and “no results” views.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltEmptyStateDescription,
  VoltEmptyStateTitle,
  VoltEmptyState,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add empty-state`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/empty-state), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import {
  VoltEmptyState,
  VoltEmptyStateTitle,
  VoltEmptyStateDescription,
  VoltNativeButton,
} from '@voltui/components';

@Component({
  imports: [VoltEmptyState, VoltEmptyStateTitle, VoltEmptyStateDescription, VoltNativeButton],
  template: `
    <!-- Empty collection: icon and actions are optional -->
    <volt-empty-state>
      <svg slot="icon" aria-hidden="true" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
        <path d="M3 7a2 2 0 0 1 2-2h4l2 2h8a2 2 0 0 1 2 2v8a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2Z" />
      </svg>
      <volt-empty-state-title>No projects yet</volt-empty-state-title>
      <volt-empty-state-description>Create your first project to get started.</volt-empty-state-description>
      <div slot="actions">
        <button voltButton>Create project</button>
      </div>
    </volt-empty-state>

    <!-- No results: same component, different words and a way out -->
    <volt-empty-state>
      <volt-empty-state-title>No matches for "{{ query }}"</volt-empty-state-title>
      <div slot="actions">
        <button voltButton variant="outline" (click)="query = ''">Clear search</button>
      </div>
    </volt-empty-state>
  `,
})
export class MyComponent {
  query = 'invoices';
}
````
