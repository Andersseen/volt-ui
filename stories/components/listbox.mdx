# Listbox

An always-visible list of options with single or multiple selection.

**Stable** · Controls · [Guide on voltui.dev](https://voltui.dev/docs/components/listbox)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Selection from a list that stays on screen, such as a settings sidebar or a multi-select list.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltListboxHeader,
  VoltListboxOption,
  VoltListboxSection,
  VoltListbox,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add listbox`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/listbox), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltListbox, VoltListboxOption } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltListbox, VoltListboxOption],
  template: `
    <volt-listbox [formControl]="selected">
      <volt-listbox-option value="angular">Angular</volt-listbox-option>
      <volt-listbox-option value="react">React</volt-listbox-option>
      <volt-listbox-option value="vue">Vue</volt-listbox-option>
    </volt-listbox>
  `,
})
export class MyComponent {
  selected = new FormControl(['angular'], { nonNullable: true });
}
````
