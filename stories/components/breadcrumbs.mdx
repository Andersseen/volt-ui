# Breadcrumbs

Shows the path to the current page.

**Stable** · Navigation · [Guide on voltui.dev](https://voltui.dev/docs/components/breadcrumbs)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Deep hierarchies where people need to go up a level.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltBreadcrumbEllipsis,
  VoltBreadcrumbItem,
  VoltBreadcrumbLink,
  VoltBreadcrumbList,
  VoltBreadcrumbPage,
  VoltBreadcrumbSeparator,
  VoltBreadcrumbs,
  VoltNativeBreadcrumbLink,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add breadcrumbs`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/breadcrumbs), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { RouterLink } from '@angular/router';
import {
  VoltBreadcrumbs,
  VoltBreadcrumbList,
  VoltBreadcrumbItem,
  VoltBreadcrumbLink,
  VoltNativeBreadcrumbLink,
  VoltBreadcrumbPage,
  VoltBreadcrumbSeparator,
} from '@voltui/components';

// <volt-breadcrumb-link href> renders its own <a>: right for a plain URL.
// <a voltBreadcrumbLink> styles the anchor YOU write, so RouterLink (or any other
// anchor directive) can own it. Volt never imports the router.
@Component({
  imports: [
    RouterLink,
    VoltBreadcrumbs,
    VoltBreadcrumbList,
    VoltBreadcrumbItem,
    VoltBreadcrumbLink,
    VoltNativeBreadcrumbLink,
    VoltBreadcrumbPage,
    VoltBreadcrumbSeparator,
  ],
  template: `
    <volt-breadcrumbs>
      <volt-breadcrumb-list>
        <volt-breadcrumb-item>
          <volt-breadcrumb-link href="/">Home</volt-breadcrumb-link>
        </volt-breadcrumb-item>
        <volt-breadcrumb-separator />
        <volt-breadcrumb-item>
          <a voltBreadcrumbLink routerLink="/docs" [queryParams]="{ tab: 'guides' }">Docs</a>
        </volt-breadcrumb-item>
        <volt-breadcrumb-separator />
        <volt-breadcrumb-item>
          <volt-breadcrumb-page>Components</volt-breadcrumb-page>
        </volt-breadcrumb-item>
      </volt-breadcrumb-list>
    </volt-breadcrumbs>
  `,
})
export class MyComponent {}
````
