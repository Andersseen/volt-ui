# Tabs

Switches between related panels, one visible at a time.

**Stable** · Navigation · [Guide on voltui.dev](https://voltui.dev/docs/components/tabs)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Splitting a page into sibling views that share a context.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltTabsContent,
  VoltTabsList,
  VoltTabsTrigger,
  VoltTabs,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add tabs`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/tabs), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltTabs, VoltTabsList, VoltTabsTrigger, VoltTabsContent } from '@voltui/components';

@Component({
  imports: [VoltTabs, VoltTabsList, VoltTabsTrigger, VoltTabsContent],
  template: `
    <volt-tabs value="account">
      <volt-tabs-list>
        <volt-tabs-trigger value="account">Account</volt-tabs-trigger>
        <volt-tabs-trigger value="password">Password</volt-tabs-trigger>
      </volt-tabs-list>
      <volt-tabs-content value="account">
        Account settings here.
      </volt-tabs-content>
      <volt-tabs-content value="password">
        Password settings here.
      </volt-tabs-content>
    </volt-tabs>
  `,
})
export class MyComponent {}
````
