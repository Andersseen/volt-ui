# Autofill

A directive that reports when the browser autofills an input, so styles and state can react.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/autofill)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Floating labels or validation that must know a value arrived from the browser, not the keyboard.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltAutofill } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add autofill`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/autofill), as you would write it in an application:

````ts
import { Component, signal } from '@angular/core';
import { VoltAutofill } from '@voltui/components';

@Component({
  imports: [VoltAutofill],
  template: `
    <input
      voltAutofill
      type="email"
      autocomplete="email"
      placeholder="Email address"
      (autofillChange)="autofilled.set($event)"
    />
  `,
})
export class MyComponent {
  autofilled = signal(false);
}
````
