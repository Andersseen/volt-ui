# Range Slider

Selects a low and a high value in a range.

**Stable** · Forms & Inputs · [Guide on voltui.dev](https://voltui.dev/docs/components/range-slider)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Filtering by a range, such as price or date span.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltRangeSlider } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add range-slider`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/range-slider), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { VoltRangeSlider } from '@voltui/components';

@Component({
  imports: [ReactiveFormsModule, VoltRangeSlider],
  template: `
    <volt-range-slider
      [formControl]="priceRange"
      [min]="0"
      [max]="500"
      ariaLabelLow="Minimum price"
      ariaLabelHigh="Maximum price"
    />
    <p>{{ priceRange.value[0] }} - {{ priceRange.value[1] }}</p>
  `,
})
export class MyComponent {
  priceRange = new FormControl<[number, number]>([50, 300], { nonNullable: true });
}
````
