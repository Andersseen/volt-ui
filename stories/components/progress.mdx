# Progress

Shows how far a task has advanced, or that one is running when the value is unknown.

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/progress)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Uploads, multi-step flows and long operations.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltProgressLabel, VoltProgressValue, VoltProgress } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add progress`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/progress), as you would write it in an application:

````ts
import { Component, signal } from '@angular/core';
import { VoltProgress, VoltProgressLabel, VoltProgressValue } from '@voltui/components';

@Component({
  imports: [VoltProgress, VoltProgressLabel, VoltProgressValue],
  template: `
    <volt-progress [value]="progress()">
      <volt-progress-label>Upload progress</volt-progress-label>
      <volt-progress-value>{{ progress() }}% complete</volt-progress-value>
    </volt-progress>
  `,
})
export class MyComponent {
  progress = signal(60);
}
````
