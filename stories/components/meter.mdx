# Meter

A gauge for a value within a known range, such as disk usage.

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/meter)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- A measurement, not task progress (use Progress for that).

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltMeterIndicator,
  VoltMeterLabel,
  VoltMeterTrack,
  VoltMeterValue,
  VoltMeter,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add meter`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/meter), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltMeter, VoltMeterTrack, VoltMeterIndicator, VoltMeterLabel, VoltMeterValue } from '@voltui/components';

@Component({
  imports: [VoltMeter, VoltMeterTrack, VoltMeterIndicator, VoltMeterLabel, VoltMeterValue],
  template: `
    <volt-meter [value]="72">
      <div class="mb-2 flex items-center justify-between gap-3">
        <volt-meter-label>Capacity</volt-meter-label>
        <volt-meter-value>72 of 100 capacity</volt-meter-value>
      </div>
      <volt-meter-track>
        <volt-meter-indicator />
      </volt-meter-track>
    </volt-meter>
  `,
})
export class MyComponent {}
````
