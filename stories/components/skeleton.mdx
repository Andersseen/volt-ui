# Skeleton

A placeholder that mimics content while it loads.

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/skeleton)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Content whose layout is known before the data arrives.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSkeleton } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add skeleton`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/skeleton), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltSkeleton } from '@voltui/components';

@Component({
  imports: [VoltSkeleton],
  template: `
    <div class="flex items-center gap-4">
      <volt-skeleton variant="circle" width="40px" height="40px" />
      <div class="space-y-2">
        <volt-skeleton variant="text" width="120px" height="16px" />
        <volt-skeleton variant="text" width="80px" height="14px" />
      </div>
    </div>
  `,
})
export class MyComponent {}
````
