# Dialog

A modal window. Open it from a trigger, control it with `[(open)]`, or open it from code and await the result with `VoltDialogService`.

**Stable** · Overlays · [Guide on voltui.dev](https://voltui.dev/docs/components/dialog)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Confirmations and short focused tasks that must interrupt the page.
- Use `role="alertdialog"` for destructive confirmations, and `initialFocus` to start on the safe action.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltDialogContent,
  VoltDialogDescription,
  VoltDialogOverlay,
  VoltDialogRoot,
  VoltDialogTitle,
  VoltDialog,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add dialog`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/dialog), as you would write it in an application:

````ts
import { Component, inject, signal, TemplateRef, viewChild } from '@angular/core';
import {
  VoltDialog,
  VoltDialogRoot,
  VoltDialogService,
  VoltDialogContent,
  VoltDialogTitle,
  VoltDialogDescription,
  VoltDialogOverlay,
  VoltNativeButton,
  type VoltDialogContext,
} from '@voltui/components';

declare function deleteProject(): Promise<void>; // your own async call

@Component({
  imports: [
    VoltDialog,
    VoltDialogRoot,
    VoltDialogContent,
    VoltDialogTitle,
    VoltDialogDescription,
    VoltDialogOverlay,
    VoltNativeButton,
  ],
  template: `
    <!-- 1. Trigger: the button opens the template -->
    <button voltButton [voltDialog]="infoTpl">Open dialog</button>
    <ng-template #infoTpl let-close="close">
      <div voltDialogOverlay></div>
      <div voltDialogContent>
        <h2 voltDialogTitle>Keyboard shortcuts</h2>
        <p voltDialogDescription>Press ? anywhere to open this list.</p>
        <button voltButton (click)="close()">Close</button>
      </div>
    </ng-template>

    <!-- 2. Controlled: your state decides when it is open -->
    <button voltButton variant="outline" (click)="editing.set(true)">Edit profile</button>
    <ng-template voltDialogRoot [(open)]="editing" (closed)="onEdited($event)" let-close="close">
      <div voltDialogOverlay></div>
      <form voltDialogContent (submit)="$event.preventDefault(); close('saved')">
        <h2 voltDialogTitle>Edit profile</h2>
        <p voltDialogDescription>Changes are visible to your team.</p>
        <!-- form fields… -->
        <button voltButton type="submit">Save</button>
      </form>
    </ng-template>

    <!-- 2b. Pending: [dismissible] is live. While a request runs, Escape and an overlay click do
         nothing; close() and [(open)] still work. initialFocus (a CSS selector inside the
         content) puts focus on the safe action instead of the first tabbable element. -->
    <ng-template
      voltDialogRoot
      role="alertdialog"
      [(open)]="deleting"
      [dismissible]="!pending"
      initialFocus="[data-cancel]"
      let-close="close"
    >
      <div voltDialogOverlay></div>
      <div voltDialogContent>
        <h2 voltDialogTitle>Delete project?</h2>
        <button voltButton data-cancel variant="outline" [disabled]="pending" (click)="close()">Cancel</button>
        <button voltButton variant="destructive" [disabled]="pending" (click)="confirmDelete(close)">Delete</button>
      </div>
    </ng-template>

    <!-- 3. Confirm: open from code and await the answer -->
    <button voltButton variant="destructive" (click)="remove()">Delete project</button>
    <ng-template #confirmTpl let-close="close">
      <div voltDialogOverlay></div>
      <div voltDialogContent>
        <h2 voltDialogTitle>Delete project?</h2>
        <p voltDialogDescription>This action cannot be undone.</p>
        <button voltButton variant="outline" (click)="close(false)">Cancel</button>
        <button voltButton variant="destructive" (click)="close(true)">Delete</button>
      </div>
    </ng-template>
  `,
})
export class MyComponent {
  private readonly dialog = inject(VoltDialogService);
  private readonly confirmTpl = viewChild.required<TemplateRef<VoltDialogContext<boolean>>>('confirmTpl');

  readonly editing = signal(false);
  readonly deleting = signal(false);
  pending = false;

  async confirmDelete(close: (result?: unknown) => void) {
    this.pending = true;
    try {
      await deleteProject(); // your own async call
      close('deleted');
    } finally {
      this.pending = false;
    }
  }

  onEdited(result: unknown) {
    console.log('closed with', result);
  }

  async remove() {
    const confirmed = await this.dialog.open<boolean>(this.confirmTpl(), { role: 'alertdialog' }).closed;
    if (confirmed) {
      // delete…
    }
  }
}
````

## Accessibility

- Focus is trapped while open and returns to the trigger on close; Escape and an outside click dismiss it (covered by e2e tests).
- Always include a `voltDialogTitle`; add `voltDialogDescription` for supporting text.
- `[dismissible]="false"` blocks Escape and overlay clicks while work is pending; `close()` still works.
