# Separator

A horizontal or vertical divider.

**Stable** · Display · [Guide on voltui.dev](https://voltui.dev/docs/components/separator)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Dividing groups of related content or toolbar controls.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import { VoltSeparator } from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add separator`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/separator), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltSeparator } from '@voltui/components';

@Component({
  imports: [VoltSeparator],
  template: `
    <div>
      <p>Section one</p>
      <volt-separator />
      <p>Section two</p>
    </div>

    <!-- Vertical separator -->
    <div class="flex h-8 items-center gap-2">
      <span>Left</span>
      <volt-separator orientation="vertical" />
      <span>Right</span>
    </div>
  `,
})
export class MyComponent {}
````
