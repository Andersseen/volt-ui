# Resizable

Panels separated by draggable, keyboard-operable handles.

**Stable** · Layout · [Guide on voltui.dev](https://voltui.dev/docs/components/resizable)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Split views such as an editor and a preview.

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltResizableHandle,
  VoltResizablePanel,
  VoltResizable,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add resizable`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/resizable), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { VoltResizable, VoltResizablePanel, VoltResizableHandle } from '@voltui/components';

@Component({
  imports: [VoltResizable, VoltResizablePanel, VoltResizableHandle],
  template: `
    <volt-resizable orientation="horizontal" class="h-64 rounded-lg border border-border">
      <volt-resizable-panel class="p-4">
        <p>Left panel</p>
      </volt-resizable-panel>
      <volt-resizable-handle />
      <volt-resizable-panel class="p-4">
        <p>Right panel</p>
      </volt-resizable-panel>
    </volt-resizable>
  `,
})
export class MyComponent {}
````
