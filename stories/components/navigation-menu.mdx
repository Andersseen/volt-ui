# Navigation Menu

A site navigation bar whose items can open rich submenu panels.

**Stable** · Navigation · [Guide on voltui.dev](https://voltui.dev/docs/components/navigation-menu)

> Recommended for production use. The public API follows the 1.x compatibility promise.

## When to use

- Top-level site navigation with grouped destinations.
- Pick how the current page is marked with `variant` (`subtle`, `pill`, `underline`, `outline`) and whether the menu draws its own surface with `layout` (`inline`, `contained`).

## Installation

Install the package and import the parts you use (the full example below also shows services and types):

```bash
npm install @voltui/components
```

```ts
import {
  VoltNavigationMenuContentItem,
  VoltNavigationMenuContent,
  VoltNavigationMenuItem,
  VoltNavigationMenuLink,
  VoltNavigationMenuList,
  VoltNavigationMenuTrigger,
  VoltNavigationMenu,
} from '@voltui/components';
```

Or copy the source into your project and own it: `npx @voltui/cli add navigation-menu`.

## Full example

The same code as the [voltui.dev guide](https://voltui.dev/docs/components/navigation-menu), as you would write it in an application:

````ts
import { Component } from '@angular/core';
import { RouterLink, RouterLinkActive } from '@angular/router';
import {
  VoltNavigationMenu,
  VoltNavigationMenuList,
  VoltNavigationMenuItem,
  VoltNavigationMenuTrigger,
  VoltNavigationMenuContent,
  VoltNavigationMenuContentItem,
  VoltNavigationMenuLink,
} from '@voltui/components';

@Component({
  imports: [
    RouterLink,
    RouterLinkActive,
    VoltNavigationMenu,
    VoltNavigationMenuList,
    VoltNavigationMenuItem,
    VoltNavigationMenuTrigger,
    VoltNavigationMenuContent,
    VoltNavigationMenuContentItem,
    VoltNavigationMenuLink,
  ],
  template: `
    <!-- variant: subtle | pill | underline | outline — how the current page is marked.
         layout: inline | contained — contained draws its own self-sized surface. -->
    <volt-navigation-menu aria-label="Main" variant="subtle" layout="inline">
      <volt-navigation-menu-list>
        <volt-navigation-menu-item>
          <!-- The panel goes in as a template reference. `content` is a required input:
               the trigger hands the template to an overlay that renders it elsewhere,
               so projecting the content instead throws NG0950. -->
          <volt-navigation-menu-trigger [content]="gettingStarted">
            Getting Started
          </volt-navigation-menu-trigger>
          <ng-template #gettingStarted>
            <volt-navigation-menu-content>
              <volt-navigation-menu-content-item>
                <a routerLink="/docs/introduction">Introduction</a>
              </volt-navigation-menu-content-item>
              <volt-navigation-menu-content-item>
                <a routerLink="/docs/themes">Themes</a>
              </volt-navigation-menu-content-item>
            </volt-navigation-menu-content>
          </ng-template>
        </volt-navigation-menu-item>
        <volt-navigation-menu-item>
          <!-- `active` marks the current destination (aria-current="page"). Derive it from
               the router as here, or pass a plain boolean when you do not use the router. -->
          <a
            voltNavigationMenuLink
            routerLink="/docs/components"
            routerLinkActive
            [routerLinkActiveOptions]="{ exact: true }"
            #components="routerLinkActive"
            [active]="components.isActive"
            >Components</a
          >
        </volt-navigation-menu-item>
      </volt-navigation-menu-list>
    </volt-navigation-menu>
  `,
})
export class MyComponent {}
````

## Accessibility

- Escape closes submenus and returns focus to the trigger; opening and swapping submenus is covered by tests. Links should be real anchors.
- `active` sets `aria-current="page"`; an open submenu is `aria-expanded` and is never marked current. Disabled links and triggers are `aria-disabled`.
- The logo, account menu and mobile shell belong to the application header, not to this component.
