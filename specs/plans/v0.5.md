## The forms contract (acceptance bar for every in-scope control)

A control passes when its spec file proves, via reactive forms (`FormControl`):

1. **write:** `control.setValue(x)` updates the rendered UI.
2. **change:** user interaction updates `control.value`.
3. **touched:** blur marks the control touched.
4. **disabled:** `control.disable()` disables the rendered element AND the ng-primitives
   directive state; user interaction while disabled does nothing.
5. **template-driven:** one `ngModel` smoke test (two-way binding works).
6. **validation styling:** invalid + touched state is visually representable (documented
   class/attr hook, e.g. `[class.invalid]` or aria-invalid passthrough).

## Phase 1 — Audit & test matrix

- [ ] For each in-scope component, read its `.spec.ts` and record which of the 6 contract
      points are already covered. (0.4.0 state: checkbox/input/switch/textarea/select have
      partial "CVA + Reactive Forms tests"; radio/slider are flagged "CVA coverage needed";
      toggle-group and search use local value APIs — verify whether they implement CVA at all.)
- [ ] Write the resulting matrix into this file (edit this section) so later phases and
      sessions don't re-audit.
- [ ] Flag any control that lacks `ControlValueAccessor` entirely — implementing it is
      Phase 2 work.

## Phase 2 — Implement missing CVA behavior

- [ ] Add/fix `ControlValueAccessor` on any control missing it (likely candidates:
      `toggle-group`, `search`; verify `toggle`). Follow the pattern used by `checkbox`.
- [ ] Ensure `disabled` propagates: forms-driven disable (`setDisabledState`) and
      attribute-driven (`disabled` input with `booleanAttribute`) must both work and compose.
- [ ] Add an `aria-invalid` / invalid-state styling hook consistently across controls.
- [ ] Keep changes minimal — no API renames in this minor unless required by the contract
      (record any rename in CHANGELOG under Changed).

## Phase 3 — Complete spec coverage

- [ ] Bring every in-scope control to the full 6-point contract in its `.spec.ts`.
- [ ] `form-field`: test label association, described-by wiring for hint/error text, and
      that projected controls (input, select, textarea) inherit the association.
- [ ] Radio: test group semantics (one checked at a time, arrow-key navigation via
      ng-primitives, group-level disabled).
- [ ] Slider: test keyboard (arrows/home/end) and `numberAttribute` inputs.

## Phase 4 — Promote, document, release

- [ ] Update `COMPONENT_STATUS.md`: controls meeting the contract move
      experimental→beta or beta→stable ("Forms support" column → "full CVA contract").
- [ ] Update demo pages + `usage.ts` snippets to show a reactive-forms example for each
      promoted control.
- [ ] `pnpm manifest` if any files were added/removed.
- [ ] `CHANGELOG.md`: add `## [0.5.0]` (Added: tests/contract; Changed: promotions & any
      API adjustments; Fixed: bugs found by the new tests).
- [ ] Bump versions to 0.5.0: root `package.json`, `projects/volt/package.json`,
      `cli/package.json`.
- [ ] Release gate: `pnpm release:check` green, then `pnpm test:e2e:ci` green.
