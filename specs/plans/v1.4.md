# Plan v1.4 — Multi-Headless Foundation

**Status:** implemented on `feat/multi-headless-foundation`; the 1.4.0 version bump is its own final commit.
**Target version:** `@voltui/components` 1.4.0 and `@voltui/cli` 1.4.0 (minor, additive). `@voltui/agent` is unchanged.
**Base:** `main` @ `1dbe866` (PR #198), `@voltui/components` 1.3.3, ng-primitives 0.131.2, Angular 21.2+ and 22.
**Rule:** the default ng-primitives implementation is untouched; Quartz is opt-in, experimental, and limited to Checkbox, Switch and Toggle.

## Decisions

1. **A secondary entry point, `@voltui/components/quartz`.** ng-packagr builds it from `packages/volt/quartz/ng-package.json`
   (`entryFile: ../src/quartz-api.ts`); the sources live in `packages/volt/src/lib/quartz/<name>/`. Same
   class names, selectors, inputs, models and outputs as the primary entry; the primary entry never imports it.
2. **Isolation is a property of the import graph, not of file layout.** The Quartz entry imports no ng-primitives and the
   primary entry imports no Quartz. Verified on the built bundles (`scripts/check-quartz-consumer.mjs`), not assumed.
3. **Helpers are bundled into the Quartz entry, not shared through the primary entry.** `cn()`, `injectFormControlState()` and
   `forwardAttributesFromHost()` are not public API and must not become public to serve a second entry; they are a few
   hundred bytes and have no identity that must be shared.
4. **The Volt CVA wrapper stays; Quartz is driven through its public directives.** `@quartz-headless/primitives/forms` is not
   used (two competing `ControlValueAccessor`s would register on one control). The wrapper maps Quartz's
   `checkedChangeCommitted` / `pressedChangeCommitted` — user activations only — onto the Volt model and `onChange`, so programmatic
   writes can never echo into Forms.
5. **Checkbox tri-state mapping.** Volt's `checked` + `indeterminate` models are folded into Quartz's `boolean | 'indeterminate'`
   for the directive. A user activation from indeterminate resolves to `checked = true, indeterminate = false`, exactly as ng-primitives does.
6. **The styling contract is normalised at the Volt boundary.** The wrapper writes `data-checked`, `data-indeterminate`,
   `data-selected` and `data-disabled` itself, so the Tailwind classes are byte-identical to the ng-primitives ones and no
   `data-qz-*` selector is needed. Toggle shares `variants.ts` (CVA) with the default implementation instead of forking it.
7. **Explicit `tabindex`.** ng-primitives writes `tabindex` on its buttons; WebKit/Safari does not Tab onto a bare native
   `<button>`. Without the same attribute Quartz controls were unreachable by keyboard in WebKit (found by the browser contract).
   The Quartz wrappers write `tabindex="0"` (`-1` when disabled).
8. **CLI.** `volt init|add --base=ng-primitives|quartz`; the base is recorded in `volt.json` and reused. The manifest gains an
   additive `backends` field (the existing format is unchanged); the Quartz file list is generated from `lib/quartz/`. Unsupported
   components, an unknown base, a base that contradicts `volt.json`, and a Quartz copy into a directory already holding ng-primitives
   copies are rejected before anything is written. Runtime packages are derived from the copied source, so a Quartz-only project is
   never told to install ng-primitives.
9. **No new component migrated, no adapter framework.** The extensible pattern is "a folder under `lib/quartz/` with the same public
   contract and a row in the shared contract spec".

## Compatibility findings (recorded, not assumed)

Angular 22 therefore fails strict peer resolution (`npm` `ERESOLVE`); `pnpm` warns. | Angular 21.2+ is supported. Angular 22 works at runtime (same suite passes) but needs `--legacy-peer-deps`/`overrides` until Quartz publishes a widened range. Documented, not hidden. |
| Quartz's own docs say Angular 21.0 does not build (toast template arrow function); Volt's minimum is 21.2.0.                                | No effect: the Volt minimum already excludes it. Verified on 21.2.0.                                             |
| Quartz has no `required` input and no Space/Enter parity beyond buttons.                                                                    | `aria-required` is written by the Volt wrapper (Checkbox).                                                       |
| Disabled Toggle: ng-primitives keeps the button focusable with `aria-disabled`; Quartz sets native `disabled`.                              | Intentional, documented difference. Everything else compared (attributes, classes, computed paint) is identical. |
| Quartz `qzCheckbox` is bound with `[checked]` (one-way); its internal write on activation is reconciled by the wrapper's committed handler. | No echo, no duplicate emission (contract tests).                                                                 |

## New dependency justification (GUARDRAILS rule 10)

`@quartz-headless/core@0.16.0` and `@quartz-headless/primitives@0.16.0` are **devDependencies of the workspace only** (to compile, test and
build the secondary entry point) and **optional peer dependencies** of `@voltui/components` (`^0.16.0`). They are not `dependencies`, so a default
consumer installs nothing new. They are the published, MIT-licensed packages of the same author; nothing is forked, vendored or consumed from a Git ref.

  through `t()`, and hard-coding copy is forbidden. The documentation lives in places that are English-only by design — Storybook
  (`stories/foundations/headless-backends.mdx`), `docs/headless-backends.md`, the package and CLI READMEs, and `CHANGELOG.md`. Follow-up once a token is
