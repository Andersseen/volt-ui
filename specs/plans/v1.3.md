## Decisions

1. **One Combobox contract.** `filterMode: 'local' | 'manual'` (default `local`) + `(queryChange)` + `loading` / `loadingText` / `emptyText` / `resultsText`. No `remote`/`async`/`server` flags. `queryChange` emits on the input event only, so the label written back after a selection never starts a request. Volt owns no fetch, debounce or cancellation.
2. **One live region.** A `role="status"` span outside the portalled dropdown announces loading, then the result count or the empty text, only while open and only after the user typed (opening an untouched list is silent). The visible loading/empty rows are `aria-hidden`; the dropdown carries `aria-busy`.
3. **Custom markup** for loading/empty was not added: strings (and `resultsText` as a function) cover i18n and `"No matches for " + query()`. A `contentChild(TemplateRef)` already means "option template", so more templates would need new marker directives for a need nobody has shown.
4. **`a[voltBreadcrumbLink]` + `VoltNativeBreadcrumbLink`**, following `voltButton`. Both link forms share `BREADCRUMB_LINK_CLASSES`. Volt does not import the router.
5. **Other anchor-rendering components audited:** only Breadcrumbs wraps an `<a>` without router support (Sidebar item already composes `routerLink`; Button has `a[voltButton]`). No other change.
6. **Alert → stable.** Two external consumers on 1.1.x, the 1.2 benchmark, package + CLI e2e, no API change in 1.2 or 1.3. **Spinner and EmptyState stay beta**: no external consumer yet.
7. **Stability has one hand-written copy** (`COMPONENT_STATUS.md`). The CLI manifest derives from it (it had 24 stable components labelled `beta`), and `product-facts.spec.ts` checks the docs catalog.
8. **No Stats block.** The P3 item needs new translated copy and the Glossa token is rejected (HTTP 401) in this environment; hardcoding strings is forbidden, and nothing else in the release depends on it.
9. **No new components** (DataTable, RemoteSelect, RelationPicker, …) and no Quartz/headless work.

## ng-primitives 0.110.2 → 0.131.2

Peer ranges allow Angular 21 and 22, so the newest release is supportable. Upstream states became input-driven and mostly read-only, and some primitives now own attributes Volt used to write.

| Upstream change                                                                       | Volt response                                                                                                                                           |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NgpButton` owns and clears `aria-disabled`.                                          | **Preserve.** `voltButton` stopped using `NgpButton` (interactions + host bindings only), so a consumer's `aria-disabled` survives.                     |
| `ngpFormControl` owns `aria-invalid` (form status only).                              | **Preserve.** `VoltAriaInvalid` re-asserts Input/Textarea's `state="error"` in the last render phase.                                                   |
| `date.set`, `role.set`, `value.set` on states removed/deprecated.                     | `select(…, {emit:false})`, `setValue`, `setDisabled`; OTP drives `ngpInputOtp()` in function form (so Volt's `○`/numeric defaults reach the primitive). |
| Dialog role comes from the per-dialog config injector.                                | Volt's `role.set` workaround removed; a spec pins it.                                                                                                   |
| ToggleGroup multiple: `radio` → button + `aria-pressed`.                              | **Adopt** (correct ARIA); spec updated.                                                                                                                 |
| Listbox: selected/first option active on focus.                                       | **Adopt**; spec updated.                                                                                                                                |
| Toast container is a `role="status"` live region.                                     | **Adopt**; `volt-toast` drops its own `status` (error stays `alert`) to avoid double announcement.                                                      |
| Popover moves focus in on open, back on close.                                        | **Adopt**; e2e updated.                                                                                                                                 |
| Listbox no longer calls `window` in SSR.                                              | SSR exception removed; a guard in `check-ssr.mjs` forbids re-adding it.                                                                                 |
| **New:** Collapsible calls `new MutationObserver` on the server when an item is open. | No safe Volt-level fix. One precise `KNOWN` entry for `/docs/components` (the index renders an open Accordion item). Upstream issue to file.            |
