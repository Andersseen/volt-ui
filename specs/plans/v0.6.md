## The overlay contract (acceptance bar)

**Modal overlays (dialog, drawer):**

1. Focus moves into the overlay on open (first focusable or designated element).
2. Focus is trapped while open (Tab / Shift+Tab cycle inside).
3. Focus returns to the trigger on close.
4. Escape closes; outside click closes (when configured); both preventable.
5. Background is inert / aria-hidden for assistive tech.
6. Body scroll is handled (locked while open, restored on close).

**Non-modal overlays (popover, dropdown-menu, tooltip, toast):**

1. Correct roles/ARIA (menu/menuitem, tooltip + aria-describedby, status/alert for toast).
2. Escape closes; outside click closes (popover/dropdown).
3. Dropdown-menu: arrow-key navigation, Home/End, Enter/Space activates, focus returns
   to trigger on close.
4. Tooltip: opens on hover AND focus, closes on blur/Escape; never traps focus.
5. Toast: auto-dismiss timer pauses on hover/focus; dismiss button reachable by keyboard.

**All overlays:** SSR-safe (component renders server-side without touching
`document`/`window` at construction), and open/close works after hydration.

## Phase 1 — Shared test utilities & audit

- [ ] Create shared Playwright helpers (e.g. `e2e/utils/overlay.ts`): `expectFocusTrap`,
      `expectFocusReturn`, `expectEscapeCloses`, `expectOutsideClickCloses`. Keep them
      dumb and reusable.
- [ ] Audit each in-scope overlay against the contract; write the gap matrix into this
      section (edit this file) so later phases/sessions don't re-audit.
- [ ] SSR audit: grep overlays for unguarded `document`/`window` usage
      (`grep -rn "document\.\|window\." projects/volt/src/lib/components/{dialog,drawer,popover,dropdown-menu,tooltip,toast}`).

## Phase 2 — Modal overlays (dialog, drawer)

- [ ] Close contract gaps found in Phase 1 (focus trap/return, inert background, scroll
      lock, Escape/outside-click configurability).
- [ ] Nested overlay behavior: dialog opening a dropdown/popover — Escape closes only the
      topmost layer. Add an e2e test for one nested case.
- [ ] Unit tests (spec files) for open/close state, ARIA attributes; e2e for focus
      behavior (drawer currently has e2e only, dialog has minimal focus coverage).

## Phase 3 — Non-modal overlays (popover, dropdown-menu, tooltip, toast)

- [ ] Close contract gaps per component (dropdown keyboard nav, tooltip hover+focus,
      toast timer pause + keyboard dismissal).
- [ ] Add missing spec files (0.4.0 state: popover/drawer/dropdown-menu/toast had little
      or no unit coverage) + e2e via the Phase 1 helpers.
- [ ] Verify positioning does not overflow the viewport (floating-ui flip/shift active) —
      one e2e assertion per positioned overlay is enough.

## Phase 4 — Promote, document, release

- [ ] Update `COMPONENT_STATUS.md`: overlays meeting the contract move
      experimental→beta (or beta→stable for dialog/tooltip if fully covered).
      Per the v1 checklist: promotion requires Escape, outside click, focus trap/return,
      nested overlays, and keyboard nav covered.
- [ ] Update demo pages/snippets where APIs gained options (e.g. dismissal config).
- [ ] `pnpm manifest` if files changed.
- [ ] `CHANGELOG.md` `## [0.6.0]`; bump root, `projects/volt/package.json`,
      `cli/package.json` to 0.6.0.
- [ ] Release gate: `pnpm release:check` then `pnpm test:e2e:ci` green.
