## Phase 0 — Keep/cut decision (do this first, it bounds everything)

Decision: keep all ten components for the v1 surface. Each is already backed by
ng-primitives or a small local behavior layer, has a documentation page, and now has
behavior coverage. Removing any of them would save less maintenance than the user value
lost.

| Component       | Decision | Reason                                                              |
| --------------- | -------- | ------------------------------------------------------------------- |
| combobox        | keep     | Core searchable-selection primitive with CVA and filtering coverage |
| listbox         | keep     | Core selection primitive; CVA and keyboard selection covered        |
| input-otp       | keep     | Common auth control; CVA and input/paste/backspace coverage         |
| date-picker     | keep     | Core forms component; CVA backed by ng-primitives date adapter      |
| file-upload     | keep     | Small output-based primitive with native disabled semantics         |
| navigation-menu | keep     | Common application navigation backed by ng-primitives               |
| table           | keep     | Static ARIA table semantics with no sorting API to harden           |
| resizable       | keep     | Pointer and keyboard behavior with separator value semantics        |
| autofill        | keep     | Narrow browser-autofill detection directive with no state API       |
| sidebar         | keep     | Static layout with tested state, navigation and tooltip dependency  |

- [x] Keep `combobox`, `listbox`, `input-otp` and `date-picker`.
- [x] Keep `file-upload`, `navigation-menu`, `resizable` and `autofill`.
- [x] Keep `table` and `sidebar`.
- [x] No public component was cut.

## Phase 1 — Value-selection composites (combobox, listbox, input-otp)

- [x] Unify value-selection APIs onto `ControlValueAccessor` while retaining compatible
      model binding.
- [x] Combobox: forms value/touched/disabled, filtering and selection are covered.
- [x] Listbox: forms contract + active-option keyboard selection coverage.
- [x] Input-OTP: forms contract + type, paste and backspace input coverage.

## Phase 2 — date-picker & file-upload (if kept)

- [x] Date-picker: CVA over `Date | null`; calendar behavior remains delegated to the
      locale-aware ng-primitives date adapter.
- [x] File-upload: native input/dropzone semantics and disabled state covered. It remains
      an explicitly output-based primitive; applications own file-list rendering.

## Phase 3 — Structural composites (navigation-menu, table, resizable, sidebar, autofill — if kept)

- [x] Navigation-menu: ng-primitives-backed focus/keyboard behavior; SSR build passes.
- [x] Table: semantic ARIA table audit complete; no sorting API exists.
- [x] Resizable: keyboard resize (arrow keys on separator with `role="separator"` +
      `aria-valuenow`) plus pointer behavior.
- [x] Sidebar layout: navigation, collapse/mobile state and tooltip dependency covered.
- [x] Autofill: retained as a narrow browser autofill-state detection directive.

## Phase 4 — Promote, document, release

- [x] `COMPONENT_STATUS.md`: every kept component is now `beta` or `stable`;
      **no `experimental` rows should remain** (cut components are removed from the table
      or moved to a "post-v1" section).
- [x] Usage snippets updated to recommend Reactive Forms; model binding remains compatible.
- [x] `pnpm manifest`.
- [x] `CHANGELOG.md` `## [0.7.0]` and root, library and CLI versions updated.
- [x] Release gate: `pnpm release:check`, docs E2E and consumer E2E green.
