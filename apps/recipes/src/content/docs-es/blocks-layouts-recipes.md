|            | Responde a                            | Ejemplo                                                   |
| ---------- | ------------------------------------- | --------------------------------------------------------- |
| **Bloque** | «Necesito esta sección en mi página.» | Hero, precios, pie de página                              |
| **Layout** | «Necesito la forma de esta pantalla.» | Panel de administración, ajustes                          |
| **Receta** | «¿Cómo hago que esto se comporte?»    | Formulario de ajustes, búsqueda asíncrona, tabla de datos |

Un bloque está **terminado**: pégalo y publica. Un layout es un **esqueleto**: pégalo y rellénalo, por eso no lleva marca. Una receta se elige por el **comportamiento** que demuestra.
