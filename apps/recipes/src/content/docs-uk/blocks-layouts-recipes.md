|            | Відповідає на                          | Приклад                                             |
| ---------- | -------------------------------------- | --------------------------------------------------- |
| **Блок**   | «Мені потрібна ця секція на сторінці.» | Hero, ціни, футер                                   |
| **Макет**  | «Мені потрібна форма цього екрана.»    | Панель адміністратора, налаштування                 |
| **Рецепт** | «Як змусити це поводитися правильно?»  | Форма налаштувань, асинхронний пошук, таблиця даних |

Блок **завершений**: вставте й публікуйте. Макет — **каркас**: вставте й заповніть, тому він без бренду. Рецепт обирають за **поведінкою**, яку він демонструє.
