Кожна сторінка закінчується панеллю **коду** та командою встановлення. Код уже переписано для звичайного проєкту: він імпортує Volt з `@voltui/components`, а не з приватного псевдоніма.

## 1. Встановіть пакети

```bash
pnpm add @voltui/components
```

Команда під кодом перелічує всі інші пакети, які імпортує запис. Її зчитано з самого коду, тож вона не може застаріти.

## 2. Скопіюйте файл

Натисніть кнопку **Копіювати** і збережіть компонент там, де ваш проєкт тримає функціональність, наприклад `src/app/blocks/pricing-tiers/pricing-tiers.ts`. Блок чи макет — це один standalone-компонент.

## 3. Використайте його

```ts
import { PricingTiers } from './blocks/pricing-tiers/pricing-tiers';

@Component({
  imports: [PricingTiers],
  template: `<app-pricing-tiers />`,
})
export class PricingPage {}
```

## 4. Застосуйте свою тему

Записи використовують лише токени теми (`bg-primary`, `rounded-md`), тож працюють ваша тема Volt і темний режим. Ніщо не має бренду.

> [!NOTE]
> Якщо хочете володіти й компонентами Volt, `npx @voltui/cli add <компонент>` копіює їх у ваш проєкт замість встановлення пакета.
