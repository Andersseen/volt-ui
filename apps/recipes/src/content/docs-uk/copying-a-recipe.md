Кожна сторінка завершується панеллю з **кодом**. Над кодом виберіть, як ваш проєкт використовує Volt UI; код, кнопка копіювання та команди встановлення відповідають цьому вибору.

| Режим           | Імпортує Volt з                  | Назви             | Встановлення                                     |
| --------------- | -------------------------------- | ----------------- | ------------------------------------------------ |
| **npm-пакет**   | `@voltui/components`             | `Volt*`, `volt-*` | `pnpm add @voltui/components` + зазначені пакети |
| **Копія (CLI)** | `../ui/<компонент>` (ваші копії) | `Ui*`, `ui-*`     | `npx @voltui/cli add …` + зазначені пакети       |

Вибір зберігається, коли ви переходите між сторінками. Обидві версії кожного запису компілюються в CI, у чистому проєкті, з пакетами, які встановлює споживач.

## 1. Встановіть потрібне

Виконайте команди під кодом. Вони зчитуються з самого коду, тож не можуть застаріти:

- **npm-пакет**: `@voltui/components` і будь-який інший пакет, який імпортує запис (більшість використовує `lumen-icons` для іконок).
- **Копія (CLI)**: `npx @voltui/cli add` з усіма компонентами Volt, які імпортує запис. CLI копіює і їхні залежності та показує потрібні їм npm-пакети (додайте `--install`, щоб встановити їх). Потім — інші пакети, які імпортує запис.

## 2. Скопіюйте файли

Скористайтеся кнопкою **Копіювати**. Збережіть назву файлу й скопіюйте в ту саму теку будь-який допоміжний файл, показаний нижче (наприклад, `contact-map.data.ts`).

- **npm-пакет**: збережіть його там, де ваш проєкт тримає функціональність, наприклад `src/app/pricing-tiers/pricing-tiers.ts`.
- **Копія (CLI)**: збережіть його в `src/app/<тека>/`. Його імпорти вказують на `../ui/<компонент>`, тобто `src/app/ui/`, куди за замовчуванням пише `volt add`. Якщо ваші компоненти лежать деінде, змініть ці шляхи.

## 3. Використайте його

```ts
import { PricingTiers } from './pricing-tiers/pricing-tiers';

@Component({
  imports: [PricingTiers],
  template: `<app-pricing-tiers />`,
})
export class PricingPage {}
```

## 4. Застосуйте тему

Записи використовують лише токени теми (`bg-primary`, `rounded-md`), тож діють ваша тема Volt і темний режим. Жодного брендування.

> [!NOTE]
> Патерни містять функцію `fake*` (`fakeSave`, `fakeSearch`, `fakeFetch`), яка заміняє ваш сервіс. Замініть її; див. [Патерни робочих процесів](/uk/docs/workflow-patterns).
