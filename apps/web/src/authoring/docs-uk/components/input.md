## Форми та доступність

- `<volt-input>` — це обгортка на всю ширину навколо одного нативного `<input>`. `id`, `class` і `aria-label` належать нативному елементу й прибираються з хоста, тож `<label for>` і `<volt-label htmlFor>` вказують на сам елемент керування, і жоден id не дублюється.
- `aria-describedby` теж застосовується до нативного input. Усередині `<volt-form-field>` його id додаються до підказки й помилки, а не замінюють їх; поза полем вони стають описом input (атрибут записується в браузері, тож сторінка, відрендерена на сервері, отримує його під час гідратації).
- Без `id` поле отримує згенерований, пронумерований у межах застосунку, тож сторінка, відрендерена на сервері, і гідратована сторінка збігаються.
- Прив’язуйте його через `[(value)]`, `formControl` / `formControlName` або `ngModel`. Введення тексту повідомляє значення; значення, яке записує ваш код (`setValue`, `reset`, зміна моделі), не повертається як зміна.
- Поле позначається торкнутим, коли втрачає фокус. `aria-invalid="true"` з’являється, коли елемент керування невалідний **і** торкнутий, або коли ви задаєте `state="error"`; сам `state` змінює лише колір.
- `required`, `readonly`, `disabled`, `type`, `name`, `placeholder` і `autocomplete` записуються в нативне поле. Елемент керування, вимкнений через Forms, теж вимикається.

## Встановлення

Скопіюйте вихідний код у свій проєкт:

```bash
npx @voltui/cli add input
```

Або імпортуйте його з пакета:

```bash
npm install @voltui/components
```
