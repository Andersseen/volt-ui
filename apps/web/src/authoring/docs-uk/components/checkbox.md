## Форми та доступність

- `<volt-checkbox>` рендерить нативний `<button role="checkbox">`; `id` і `aria-label` переходять на нього. Назвіть його через `<volt-label htmlFor>`, що вказує на його `id`, або через `aria-label`.
- `aria-checked` має значення `true`, `false` або `mixed` (`indeterminate`). Пробіл активує його; активація змішаного прапорця робить його позначеним і повідомляє `indeterminateChange(false)`.
- З Forms значення елемента керування — булеве `checked`. Активація користувачем повідомляє його один раз і позначає елемент як змінений; значення, яке записує ваш код, — ні.
- `indeterminate` лишається вашим: запис через Forms значення, яке прапорець уже має (початковий запис, батьківський «вибрати все», що повторно синхронізується), його зберігає; запис, що змінює значення, його скасовує.
- Позначається торкнутим при втраті фокуса; `aria-invalid="true"`, коли елемент керування невалідний і торкнутий. `required` задає `aria-required`.
- Без `id` отримує згенерований, пронумерований у межах застосунку, тож серверний рендеринг і гідратація збігаються.
- Експериментальна точка входу Quartz (`@voltui/components/quartz`) проходить ті самі контрактні тести.

## Встановлення

Скопіюйте вихідний код у свій проєкт:

```bash
npx @voltui/cli add checkbox
```

Або імпортуйте його з пакета:

```bash
npm install @voltui/components
```
